
# ✈️ 飞机维修任务管理系统
> 面向飞机维修场景的任务管控平台，支持维修任务下发、工具借用、航材申领、任务全流程跟踪。
> 前端访问地址：https://aircraft-maintain.netlify.app
> 后端api地址：aircraft-backend.up.railway.app
> 前端部署平台:Netlify
> 后端部署平台：Railway
> 数据库托管平台：MongoDB Atlas
> 代码托管平台：Github

## 📦 系统模块
- 任务模块
- 用户模块
- 航材模块
- 工具模块
- 记录模块

## 👥 角色权限说明
### 管理员
拥有平台全部权限：任务管理、工具管理、航材管理、用户管理。
1. 登录系统，在任务模块编辑、创建维修任务
2. 任务编辑完成后下发任务给员工

### 工具管理员
仅拥有工具管理权限：
1. 工具录入、信息维护
2. 员工借用工具：工具出库登记
3. 任务完成后：工具回收入库

### 航材管理员
仅拥有航材管理权限：
1. 航材信息录入维护
2. 员工申领航材，完成航材发放

### 普通员工
1. 查看管理员下发的维修任务，领取任务
2. 查看任务配套所需工具、航材
3. 向管理员申领工具与航材
4. 维修任务结束后归还工具

## 📖 业务流程简述
管理员下发任务 → 员工领取任务 → 员工申领航材 / 借用工具 → 开展维修 → 任务完成 → 工具归还入库
