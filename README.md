飞机维修系统
此系统是在飞机维修工作方面的一个平台，用于任务下发，工具借用，航材领取，任务结束。全程跟踪维修任务。包含以下几个模块,任务，用户，航材，工具，和记录模块。
系统的使用说明
管理员用户登录后在任务模块来编辑管理任务，编辑任务成功后来下发任务。管理员拥有此平台所有权限，任务管理，工具管理，材料管理，用户管理。
工具管理员只有工具管理权限，在工具页面管理工具，录入工具，出借工具，回收工具，当有员工来借用工具后找到借用的工具然后出库借给员工，当员工完成任务后归还工具入库。
材料管理员只有材料管理权限，在材料页面管理材料，录入材料，当员工来领取材料后下发材料给员工。
员工在系统内看到管理员下发的任务以后，选择领取任务，查看任务信息，任务所包含的工具和材料，到材料和工具管理员处借用和领取工具，在任务完成以后，归还维修工具。
